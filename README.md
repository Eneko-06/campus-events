# Campus Events

Campus Events is a web application built with Angular and Node.js, that shows us an interface we can interact with, and behind it there's a program that receives these requests and responds to them..

## How to run the application

### Start the server

Open a terminal in the project root and run:

    node server/hello.js

The server runs at http://localhost:3000.

### Start the client

Open a second terminal and run:

    cd client
    ng serve

The Angular application is available at http://localhost:4200.
